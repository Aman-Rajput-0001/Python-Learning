## 🛠️ Mini Projects

### 1. 🏧 [ATM Machine Simulator](atm.py)
A CLI-based ATM simulation providing:
- PIN authentication
- Cash withdrawal with balance check
- Balance enquiry & deposit features
- Interactive user loop

### 2. 💰 [Expense Tracker](expense_tracker.py)
A lightweight personal finance tracker supporting:
- Adding daily expenses with categories and timestamps
- Viewing total spending
- Calculating highest expenditure
- Filtering today's expenses

### 3. 🎯 [Number Guessing Game](game.py)
A fun console game utilizing Python's `random` module:
- Generates random numbers within a range
- Gives "Think Larger" / "Think Lower" hints
- Tracks total user attempts

## 🚀 Getting Started

### Prerequisites
Make sure you have [Python 3.x](https://www.python.org/downloads/) installed.

### Running a script
Clone or navigate to the directory and run any script using Python:

```bash
# Run HackerRank practice solutions
python hackerrank_partice_q.py

# Run the ATM Simulator
python atm.py

# Run the Expense Tracker
python expense_tracker.py

# Run the Guessing Game
python game.py
```
